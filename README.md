# Weather App 🌤️

A simple weather app that shows current weather for any city using the OpenWeatherMap API.

## Features

- Search weather by city name
- Shows temperature, humidity, and wind speed
- Dynamic weather icons
- Error handling for invalid cities
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## How to Use

1. Open `weather.html` in your browser
2. Enter a city name in the search box
3. Click search to see the weather

## Setup

No installation needed! Just open the HTML file in any browser.

**Optional:** Get your own API key from [OpenWeatherMap](https://openweathermap.org/api) and replace it in `script.js`.
